# Calculadora em PHP 🧮

Um projeto simples e elegante de uma calculadora web desenvolvida com as quatro operações matemáticas básicas. Este projeto foi construído para colocar em prática conceitos de lógica de programação.

## 🚀 Funcionalidades

- **Soma, Subtração, Multiplicação e Divisão.**
- Tratamento de erro para divisão por zero.
- Interface moderna (UI) utilizando HTML e CSS puro.
- Conversão automática de ponto para vírgula no resultado final.

## 🛠️ Tecnologias Utilizadas

- **PHP 8+** (Lógica de processamento)
- **HTML5** (Estrutura e formulários)
- **CSS3** (Estilização visual e responsividade)

## ⚙️ Como executar este projeto no seu computador

Como este projeto utiliza PHP, você precisará de um servidor local (como o **XAMPP**) para rodá-lo.

1. Faça o download ou clone este repositório.
2. Mova a pasta do projeto para o diretório de arquivos públicos do seu servidor local (no XAMPP, geralmente é a pasta `C:\xampp\htdocs`).
3. Inicie o serviço **Apache** no painel de controle do XAMPP.
4. Abra o seu navegador e acesse: `http://localhost/nome-da-sua-pasta` (ou o nome que você deu ao repositório).
